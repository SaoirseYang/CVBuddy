# 自维护网申助手（Chrome/Edge 插件 v0.5）

可自己维护的网申自动填写助手。针对牛客"网申助手"的三个短板做了针对性设计：

1. **先扫描、出方案、再填写**：点"扫描预览"先生成整页"字段 → 资料项 → 写入值"清单（含下拉选项比对、未识别字段列表），核对无误后一键填写；
2. **分段表单循环填写**：填一段 → 自动点"保存/确定" → 自动点"添加/＋" → 继续下一段；
3. **策略自适应**：自动识别"从最高学历填起 / 从高中填起 / 不需要填高中"等要求，顺序与范围自动调整，并按站点沉淀记忆；
4. **开放可维护**：站点规则与词典全部本地可编辑（资料库里有图形界面），支持教学模式手工映射、导入导出。

## v0.5 新增

- **页面内面板**：页面右下角"网申"按钮，随时扫描 / 填写 / 看进度 / 看未识别字段；未识别字段可当场点"映射"选资料项或填固定值，立刻沉淀成该站点规则（再也不用重开弹窗看日志）。
- **本地桥接（直连 WorkBuddy）**：不用再手动导出快照。启动 `tools/bridge-server.js` 并在弹窗勾选"实时同步给 WorkBuddy"，当前页面的字段诊断与扫描方案会实时推到 `tools/live/`，WorkBuddy 可直接读取你的实时页面并下发指令（扫描 / 填写 / 定位元素）。
- **字段词典页（可自维护）**：资料库 → 字段词典。把"页面上的字"与"资料项"对应起来，全站长期生效；支持筛选、批量添加、逐词删除、查看内置词。
- **固定值**：站点规则支持"该字段固定填 XX"。已内置英特尔的工号 → 填"无"（页面原文"未在英特尔工作过请填无"）。
- **站点规则可视化编辑**：映射表（匹配文字 / 资料项或固定值 / 值）、填写顺序、是否含高中、按钮文案、区块关键词，另有原始 JSON 兜底。
- **资料库界面重做**：分"资料 / 配置"两组导航与搜索，条目式卡片编辑（上移/下移/复制/删除）。
- **扫描器修了一批真问题**（离线回归脚本 `tools/test-fill.js`）：
  - 不再把顶部跳转标签（"教育经历 | 实习经历 …"）当成区块标题，避免把整张表圈成一个区块导致**基础字段全被跳过**；
  - 题干在深层容器里（Intel 的 `.field-value`）也能取到，并会剥离"请填写…/必填字段不能为空"等提示噪音；
  - `是/否`、`男/女`、`有/无` 这类选项组能反推出题干（"性别""海外留学经历"）；
  - `name`/`id` 一律写成 `value` 的站点不再误判；附件上传组件内的辅助框、手机区号选择器自动跳过。
  在 Intel 校招快照上，从"可填 0"提升到"可填 12 / 未识别 10"，其余未识别项均为个人化问题（如"有英特尔的实习经历？"），可用面板一键映射。

## 安装（无需构建）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）；
2. 打开右上角（Edge 为左侧）"开发者模式"；
3. 点击"加载已解压的扩展程序"，选择本目录 `wangshen-assistant` 文件夹；
4. 建议把插件图标固定到工具栏。

## 使用

1. 先点插件图标 → "打开资料库"，把基本信息、教育经历（含高中）、实习/项目、奖项等板块填好（支持直接导入牛客数据，见下）;
2. 打开目标网申页面，点插件图标 → 选好顺序/高中策略（默认"自动"）→ **开始填写本页**；
3. 页面右下角"网申"面板会实时显示进度；填完**人工核对后再提交**（插件永远不会自动点"提交"）；
4. 遇到没认出来的字段：在面板里点该字段的"映射"，选资料项或填固定值，**下次同一站点自动填**；也可在"资料库 → 字段词典"里加关键词（全站生效）；
5. 想在对话里让 WorkBuddy 直接看你的页面：启动本地桥接（见下），弹窗勾选"实时同步给 WorkBuddy"。

## 本地桥接（可选，推荐）

```bash
# 在插件所在项目目录下执行（保持窗口开着）
node wangshen-assistant/tools/bridge-server.js
```

然后在插件弹窗勾选"实时同步给 WorkBuddy"。之后 WorkBuddy 可以：

- 读取 `wangshen-assistant/tools/live/latest.json`（当前页每个控件的识别结果、可填/未识别清单）与 `latest.html`（含已填值的整页 DOM）；
- 下发指令：`curl -X POST http://127.0.0.1:8765/enqueue -H "Content-Type: application/json" -d '{"op":"sync"}'`
  （`op` 可为 `sync`/`dump`/`diag`/`plan`/`fill`/`stop`/`highlight`，`highlight` 需带 `selector`）。

安全说明：桥接只监听 `127.0.0.1`，数据不出本机；关掉窗口或取消勾选即断开。

### 内置站点规则

`src/shared/builtin-rules.js` 存放随插件分发的站点规则（域名匹配、用户规则优先级更高）。已有 Moka 系统（app.mokahr.com）、英特尔校招（chinacampus.jobs.intel.cn）、中华英才网（applyjob.chinahr.com）三个种子条目，会随快照分析持续充实。规则可自定义 `ui.addWords`（添加按钮文案）、`ui.saveWords`（保存按钮文案）、`ui.sectionHints`（区块标题关键词）。

### 策略自适应说明

优先级：**弹窗手动选择 > 站点规则沉淀 > 页面文本推断 > 默认（最新优先、全量）**。

- 页面出现"请从最高学历开始填写"→ 自动最新优先；出现"从高中填起"→ 自动最早优先；
- 页面出现"无需填高中"→ 自动过滤高中段；
- 每次填写后，生效的策略会写入该站点规则，下次打开同一站点自动套用。

### DeepSeek AI 兜底（可选）

在"资料库 → 设置与备份"里填入 DeepSeek API Key 并开启。本地词典和站点规则都没命中的字段才会请求 AI，识别结果会自动写回站点规则缓存（越用越准）。**不填 Key 完全不影响其他功能。**

### 从牛客网申助手迁移数据

如果之前在牛客的网申插件里填过简历，无需重录：

1. 打开牛客简历页（www.nowcoder.com/my/resume-plugin...），用本插件的"导出页面快照"按钮导出 HTML；
2. 运行 `cd tools && node migrate-nowcoder.js ../site-cases/snapshot-www.nowcoder.com-xxx.html`；
3. 生成 `import-nowcoder-profile.json`，在"资料库 → 设置与备份 → 导入备份"中选择该文件即可。

也可直接使用仓库里已生成的 `import-nowcoder-profile.json`。

### 支持的资料板块（v0.3，与牛客插件对齐并开放自定义）

基本信息（含身高体重/健康状况/特长/紧急联系人等）、求职意向、教育经历（含学院/专业课程/研究方向/毕业论文/海外经历/辅修/导师）、实习/工作经历（含工作类型/薪资/工作成果/证明人/离职原因/下属人数）、项目经历（含本人职责/项目成果/项目链接）、在校经历（社团/社会实践）、获奖情况、外语能力、计算机技能、资格证书、家庭情况、论文期刊、专利、竞赛、作品集。所有板块都可在资料库中自由增删条目，且站点规则、词典均可自行扩展。

## 站点规则格式（rules 数据）

```json
{
  "domain": "career.xxx.com",
  "fieldRules": [
    { "match": { "label": "毕业院校" }, "from": "edu.school" },
    { "match": { "name": "candidateName" }, "from": "basic.name" }
  ],
  "strategy": { "order": "earliest-first", "includeLevels": ["硕士", "本科", "高中"] }
}
```

- `from` 可用路径见 `src/shared/dictionary.js`（basic.* / edu.* / work.* / prj.* / awd.*）；
- `strategy.includeLevels` 删掉 "高中" 即表示该站点不填高中。

## 当前限制（v0.1 → 后续迭代）

- 上传类控件（照片/附件简历）暂不支持自动上传；
- 级联选择器（省市区/院校库）和复杂日历组件的适配会在后续版本逐个积累；
- "添加"按钮的识别基于常见文案（添加/新增/＋），个别站点需用教学模式或手工处理；
- 表格里的 label 推断对非常规 DOM 结构可能失效，此时用教学模式补规则即可。
